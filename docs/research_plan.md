# 论文预期流程与研究方案

## 一、研究题目与定位

### 1.1 拟定题目

**基于元学习与图神经网络的触觉传感器协同激活预测研究**

英文题目暂拟为：

*Meta-Learning and Graph Neural Networks for Predicting Tactile Sensor Co-activation*

题目可在完成数据核验、明确协同关系定义及确定最终方法后进一步调整。

### 1.2 学科定位

本研究拟以统计学硕士学位论文的要求组织工作，研究重点不只是搭建一个由 Transformer、GCN 和 MAML 组成的复杂模型，而是围绕少样本条件下的触觉传感器协同关系估计与预测，开展统计定义、结构化建模、跨物体验证和不确定性分析。

研究将综合使用多变量时间序列分析、相关性估计、图结构建模、概率预测、少样本学习及统计推断等方法。深度学习模型是解决研究问题的工具，而不是研究目的本身。

### 1.3 研究边界

当前研究聚焦于**触觉传感器之间协同关系的预测**。现阶段不直接研究机器人控制策略，也不声称已经实现抓取稳定性提升、实时控制或工业部署。上述方向仅作为潜在应用背景，除非后续增加相应实验，否则不作为本文已验证的结论。

本文所称“协同激活”首先是一个可操作化的统计关系概念。若采用相关系数阈值构造标签，预测对象应准确表述为“基于指定时间窗口和阈值定义的统计协同关系”，不能直接将其解释为因果关系或真实物理协作机制。

---

### 1.4 数据模态与研究范围锁定（pressure-only）

本研究后续实验统一限定于 STAG pressure-only 数据版本及其配套 `metadata.mat`。不下载、不处理、不标注同步视频或图像帧，不开展视觉识别和触觉—视觉多模态融合。研究仅使用压力序列、官方元数据字段和由压力序列计算得到的统计量。

这一范围选择是对硕士论文工作量和研究问题的控制，不意味着压力数据能够验证所有物理接触事实。缺少同步视觉证据时，事件标记的有效性只能通过压力曲线、官方元数据一致性、算法敏感性和统计稳定性进行内部审查；不能声称已完成人工视觉核验，也不能将压力信号上的操作性标签等同于独立物理真值。

对于缺少官方事件锚点的 Recording，不使用未经验证的自动候选事件补标。它们保留在 `hasValidLabel` 原始压力对照分析中，但不纳入依赖官方基线锚点的分解分析。对于阈值规则排除但仍被 `hasValidLabel` 标记的事件，保留为阈值敏感性和标签覆盖率分析对象，不在缺少外部证据时将其直接判定为误标。

## 二、研究背景与核心问题

触觉传感系统通常由多个空间分布的传感器构成。物体接触和抓取过程中，各传感器会产生随时间变化的压力响应。不同传感器的响应可能表现出同步变化、空间关联或一定的时间依赖。

在实际感知场景中，面对一个此前未见过的物体，系统可能只能获得有限的早期触觉观测。如何利用这些有限观测，预测该物体后续阶段不同传感器之间可能形成的协同关系，是一个具有研究价值的问题。

与普通的单变量预测或分类不同，本研究的预测对象是传感器两两之间的关系结构；与传统的同分布训练测试划分不同，本研究重点考察模型从已见物体迁移到未见物体的能力。

### 2.1 核心科学问题

**在少样本条件下，如何利用早期触觉观测及有限的统计和空间结构信息，稳定地预测未见物体上的传感器协同关系？**

### 2.2 拟回答的三个研究问题

- **RQ1：协同关系能否被可靠估计？** 短时间窗口下，传感器相关性及由此构造的协同标签有多大不确定性？窗口长度、相关性估计方法和阈值会如何影响关系结构？
- **RQ2：哪些信息有助于预测协同关系？** 传感器自身的时序统计特征、传感器之间的统计关系以及空间结构信息，分别能带来多少增量预测价值？
- **RQ3：元学习能否改善跨物体少样本泛化？** 与普通监督学习及其他基线相比，元学习是否能在未见物体上带来稳定、可重复且具有实际意义的性能提升？这种提升是否依赖物体类型、Support 样本量或任务划分？

### 2.3 研究假设（待检验）

- H1：仅使用早期触觉观测构造的统计特征，对后续窗口定义的协同关系具有一定预测能力。
- H2：在传感器自身特征之外加入传感器间关系信息和空间结构信息，可能改善协同边预测。
- H3：当训练物体与测试物体存在任务层面的差异时，元学习可能比不进行任务级适应的普通监督学习更有利于少样本泛化。
- H4：不同物体、不同观测窗口和不同协同关系定义下，模型表现可能存在明显差异。

上述假设均需由实验检验，不预设其成立。

## 三、数据基础与数据审查

### 3.1 当前数据方案

当前研究方案拟使用 MIT HumanGrasp（STAG）相关触觉数据。前期方案记录的数据概况为：

- 约 26 种日常物体；
- 约 548 个有效压力传感器；
- 约 13.5 万帧压力数据；
- 单帧压力观测约为 548 维。

**以上数字是当前方案中的数据描述，正式研究前必须依据实际下载的数据、数据集论文及官方说明逐项核验。** 在完成核验前，不应将这些数字作为已审计的数据事实写入论文最终稿。

### 3.2 数据审查任务

正式建模前，先形成数据审查记录，至少包括：

1. 数据集官方名称、版本、来源、引用方式及许可条件；
2. 物体类别数量、每类物体对应的抓取片段数量；
3. 传感器数量、传感器编号、空间坐标及有效性标记；
4. 时间戳、采样频率、缺失值、异常值和重复记录；
5. 每个抓取片段的起止位置及物体、试次等分组标识；
6. 不同物体和抓取片段的数据长度分布；
7. 数据预处理和标签构造所需字段是否真实存在。

数据审查结果应保存为可复现的统计摘要，不应只在代码中隐式处理。

### 3.3 样本独立性与划分原则

约 13.5 万帧不等于 13.5 万个独立样本。相邻帧、同一抓取片段的滑动窗口，以及同一物体产生的多个 Episode 可能具有较强依赖性。

研究目标是跨物体泛化，因此主实验应优先按照**物体分组**划分训练集、验证集和测试集，保证测试物体不参与模型训练、特征标准化参数估计、阈值调节和模型选择。

初始方案中的 70%/15%/15% 物体划分可作为候选方案，但需要结合实际物体数量确定整数分配。若总计为 26 个物体，划分大致为 18/4/4；这意味着测试物体数量较少，单次划分的结果可能对个别物体较敏感。因此还应开展多个随机物体划分或重复分组验证，并明确报告每次划分包含的物体。

若数据中存在同一物体的多个独立抓取试次，可在物体级划分之外进一步保留试次分组信息，用于检查同物体内的重复观测依赖，但不能以试次级划分替代跨物体测试。

### 3.4 数据泄露控制

所有模型输入、统计画像、图结构先验、标准化参数和特征选择结果，都必须仅使用训练阶段可用的数据以及预测时点之前已经观测到的信息。

若任务定义为使用前 5 帧预测后续 10 帧，则：

- 输入特征只能由前 5 帧构造；
- 标签只能由后续 10 帧按预先规定的规则构造；
- 不得使用完整抓取序列的均值、峰值、偏度等统计量作为早期预测输入；
- 标准化参数只能由训练数据估计；
- 测试物体不能参与超参数选择、阈值选择或模型训练；
- 同一抓取片段产生的重叠窗口不能跨越训练、验证和测试边界。

## 四、任务定义与统计标签构造

### 4.1 预测任务

设一个抓取片段中有 $N$ 个有效传感器。第 $i$ 个传感器在时刻 $t$ 的压力观测记为 $x_i(t)$。

在当前方案中，拟采用早期 $K$ 帧作为输入，后续 $H$ 帧作为标签构造窗口。原方案曾将 $K=5$、$H=10$ 作为候选设置。完成真实数据审查后，暂不采用 $H=10$ 作为主标签窗口，因为短窗口相关估计稳定性不足。当前数据驱动的候选协议改为：输入取最早 5 个有效物体接触帧，目标在其后的全部有效物体接触帧上估计 Recording 级关系矩阵；具体定义见本节 4.5。

模型输入为早期观测及其派生特征，主要输出为传感器对 $(i,j)$ 的未来关系强度；若采用二元辅助任务，则输出正向协同概率：

```math
\hat{p}_{ij}
=
P\left(
Y_{ij}=1
\mid
\mathcal{F}_{\mathrm{early}}
\right)
```

其中，$\mathcal{F}_{\mathrm{early}}$ 表示预测时点可获得的早期观测信息。

### 4.2 协同关系的操作性定义

对传感器对 $(i,j)$，在未来观测集合上计算 Pearson 相关强度：

```math
R_{ij}^{(\mathrm{future})}
=
\mathrm{Corr}\left(
x_i(t),x_j(t)\mid t\in\mathcal{F}_{\mathrm{future}}
\right)
```

第一版候选方案将连续相关强度（或 Fisher-$z$ 变换）作为主要预测目标：

```math
Z_{ij}=\operatorname{atanh}(\operatorname{clip}(R_{ij},-1+\epsilon,1-\epsilon))
```

为便于解释，可另定义正向协同二元标签：

```math
Y_{ij}^{(\tau)}=\mathbb{1}(R_{ij}^{(\mathrm{future})}\geq\tau)
```

其中，$\tau=0.7$ 暂作候选阈值，$0.5$ 和 $0.9$ 用于敏感性分析。该标签只表示指定未来观测集合中的正向线性相关，不表示因果关系，也不必然等价于生理或物理意义上的协同机制。负相关不计入正向协同边，应作为不同方向的关系单独保留或分析。

### 4.3 标签定义需要解决的问题

1. **观测长度与非平稳问题：** 短窗口相关系数估计不稳定；即使聚合更多未来帧，也需检查前后时段关系结构是否一致。
2. **阈值问题：** $\tau=0.7$ 是候选设定，不应只报告单一阈值结果；需要开展阈值敏感性分析。
3. **方向问题：** 正相关 $r_{ij}\geq 0.7$ 与绝对相关 $|r_{ij}|\geq 0.7$ 定义不同。若研究正向同步激活，标签、输入特征和解释必须保持一致；负相关不能被绝对值特征无差别地视为正向协同。
4. **常数序列问题：** 当某个窗口内传感器压力没有变化时，相关系数可能无法定义。必须预先规定无效边的处理规则，并报告无效比例。
5. **类别不平衡问题：** 应先统计完整候选边集合中的正负边比例，再决定训练采样策略。若为计算方便进行正负平衡采样，评估时应同时提供能够反映自然类别比例的结果或明确说明采样分布的影响。
6. **标签噪声问题：** 需要评估不同窗口、试次和估计方法下标签的一致性，不应把由短窗口估计产生的二元标签当作无误差真值。

### 4.4 备选统计定义

可将以下定义作为稳健性分析，而不是在未验证前全部纳入主模型：

- Spearman 秩相关：检验单调关系下的稳健性；
- 收缩相关估计：在样本较短时探索对相关矩阵的正则化；
- 不同时间窗口的 Pearson 相关：检验时间尺度影响；
- 保留正负方向的相关特征：避免绝对相关造成语义混淆。

最终主标签应选择一个定义清晰、可重复、与研究问题一致的方案，其余定义用于敏感性分析。

### 4.5 基于真实数据的第一版候选标签协议

对每个非空手 Recording，按时间顺序取 `hasValidLabel=True` 的物体接触帧。输入为最早的 $K=5$ 个有效接触观测；目标集合为同一 Recording 中其后的全部有效接触帧。对传感器对 $(i,j)$，在目标集合上计算连续 Pearson 相关系数 $R_{ij}$，并优先预测连续关系强度（可采用 Fisher-$z$ 变换）。二元正向协同标签 $Y_{ij}=\mathbb{1}(R_{ij}\geq\tau)$ 作为辅助任务，候选阈值为 $0.5,0.7,0.9$。

本地首轮审查得到 78 个非空手 Recording、26 个物体（每类 3 个 Recording）、548 个有效传感器。每个 Recording 扣除早期 5 帧后，未来有效接触帧为 410–1,922 帧，中位数 910 帧。阈值 $\tau=0.7$ 时，Recording 级平均正边比例约 0.574%。将未来帧按时间分半后，正边集合 Jaccard 中位数约 0.138，提示二值边标签存在明显时段敏感性，因此不能直接将二值标签视为无误差真值。

该协议是基于 `hasValidLabel` 的原始压力对照定义。后续已增加基于官方事件标记的手部姿态基线相减方案，见本节 4.6。原论文的信号分解应作为后续敏感性分析和方法核验，不应声称当前版本已经获得纯物体相关信号。详见 `docs/coactivation_definition.md`。

此外，早期 5 个有效接触帧并非每个 Recording 都连续；后续需对连续帧约束和最大输入时间跨度开展敏感性分析。跨物体泛化必须以 object 为分组单位，不能直接使用官方 Recording 级 `splitId` 作为未见物体测试。

需要说明，`hasValidLabel` 是数据集预处理生成的接触有效性标记。当前输入选择条件于该标记，属于接触有效帧已筛选的研究任务，不等同于未经筛选原始流上的端到端在线预测。若论文声称在线应用，必须另行实现只使用预测时点之前信息的因果接触检测器，并验证不使用测试 Recording 的未来信息。

### 4.6 STAG 手部姿态与物体压力分解后的标签修订候选

重新审查 pressure-only 数据后，发现 MAT 中包含原论文信号分解使用的事件标记：`isTransition`、`isGrasp` 和 `transitionDir`。官方 HTML README 将 `isGrasp` 拼写为 `isGrap`。本研究将 `isTransition` 作为接触前基线锚点，并将 `transitionDir` 解释为向前到关联接触峰值的帧偏移；README 未正式定义该字段。经验核验显示，在 448 个可靠事件中，按该偏移得到的峰值锚点有 87.9% 位于平滑均值信号局部极大值的 ±3 帧内，因此该解释具有数据支持，但仍应标注为操作性解释。原论文检测器的完整代码未公开，本阶段使用官方事件锚点，不声称独立复刻了完整局部极值检测器。

压力预处理采用原论文的 500–650 到 0–1 归一化、548 个物理传感器逐帧均值，以及标准差为 3 帧的对称 Gaussian 平滑。对可靠抓取事件，在接触峰值附近按 0.5 阈值提取窗口，并从每帧压力向量减去对应接触前基线帧，得到物体相关压力信号。论文未用公式明确给出 0.5 阈值的归一化分母。结合前文的 Recording dynamic range 描述，当前将 Recording 全局 min–max 归一化（recording-relative）作为主分析候选；接触前基线到接触峰值的局部归一化（event-relative）保留为敏感性分析，不能将后者写成论文明确指定的规则。

真实数据审查得到 1,740 个接触前锚点、448 个可靠抓取事件，覆盖 74 个 Recording。recording-relative 模式构造 317 个窗口、4,999 个去重帧；event-relative 模式构造 446 个窗口、6,652 个去重帧。全局阈值未通过的 131 个峰值帧全部仍被 `hasValidLabel=True` 标记，说明该阈值具有保守筛选作用，可能舍弃数据集标记为物体持有的弱接触事件。两种规则的窗口边界也存在明显差异，已对代表性事件进行曲线可视化抽查。

另有 4 个 Recording 没有任何 `isTransition` 或 `isGrasp` 标记：3 个 chain Recording 和 1 个 kiwano Recording，合计仍包含 4,368 个 `hasValidLabel` 帧。对它们试运行论文文字启发的梯度/局部极值检测会产生大量未经验证的候选，故不自动补标，也不混用原始接触帧基线。当前分解主分析排除这 4 个 Recording，保留其在原始 `hasValidLabel` 对照分析中的结果；因此分解主分析只覆盖 25 个物体类别，chain 类别没有可用 Recording，kiwano 剩余 2 个。

在 recording-relative 候选下，全部 `hasValidLabel` 原始帧与事件窗口原始帧的正边 Jaccard 中位数为 0.057；同一事件窗口内，原始压力与基线相减后物体压力的边 Spearman 中位数为 0.590、\(\tau=0.7\) 正边 Jaccard 中位数为 0.461；全部原始有效帧与分解后物体压力的 Jaccard 中位数为 0.048。手部姿态基线与物体压力的边 Spearman 中位数为 0.184。所有统计以 Recording 为汇总单位；Spearman 在每个 Recording 中最多抽取 20,000 条共同有效边估计，Jaccard 和平均绝对相关差使用完整共同有效边。

因此，下一版主标签候选仍是**可靠事件窗口内基线相减后的物体相关压力相关矩阵**；原始 `hasValidLabel` 相关矩阵保留为对照/消融条件。但由于 0.5 分母尚未被原作者代码证实、131 个事件被全局阈值排除、4 个 Recording 缺少官方事件锚点，且没有独立物体压力真值，目前不能将其锁定为无误差的最终标签。详细方法、可视化抽查和复现命令见 `docs/stag_signal_decomposition.md`。




### 4.7 协同关系标签稳定性与估计方法比较（已完成首轮）

本轮基于 26 个物体、78 个 Recording 和 548 个传感器完成 pressure-only 首轮审查。未来目标仍为最早 5 个 hasValidLabel 帧之后的全部有效接触帧。比较 Pearson、Spearman 和 Ledoit-Wolf 收缩相关；并检查分解事件窗口的 expanded/unique 帧计数及 pooled/event-balanced 相关矩阵差异。

主要结果：Pearson 与 Spearman 的边相关 Spearman 中位数为 0.847；Pearson 与 Ledoit-Wolf 为 0.9997，平均绝对相关差中位数为 0.0083，Ledoit-Wolf 收缩系数中位数为 0.0254。70 个至少有一个合格未来事件窗口的 Recording 中，仅 Recording 049（tape）存在明显窗口重叠，expanded 634 次帧出现、unique 296 帧；其余 Recording 无重复帧。原始压力 expanded/unique 相关矩阵的边 Spearman 与 tau=0.7 Jaccard 中位数均为 1.000。

对基线相减压力，pooled event-frame 与等事件权重 Fisher-z 平均矩阵的边 Spearman 中位数为 0.213、tau=0.7 Jaccard 中位数为 0.018，表明事件长度加权与事件等权对应不同目标。时间块 Bootstrap（块长 10 帧、20 次、96 个节点）得到边 Spearman 中位数 0.925、tau=0.7 Jaccard 中位数 0.539。事件级 Bootstrap（每事件至少 5 帧、100 次、64 个节点）在 60 个 Recording 上可计算区间，95% 区间宽度中位数 0.440，区间不含 0 的边比例中位数 25.6%。以上 Bootstrap 均为子节点和有限重复次数的探索性诊断，不是全部边的正式置信区间。

当前建议：主标签暂保留未来 hasValidLabel 有效接触帧上的连续 Pearson 相关；Spearman 作为稳健性对照，Ledoit-Wolf 作为收缩估计对照；基线相减的物体相关压力标签保留为候选替代和消融，不以 event-balanced 结果取代主标签。详见 `docs/coactivation_stability.md`。


### 4.8 时间块 Bootstrap 块长敏感性与标签冻结候选（已完成）

在 78 个 Recording、26 个物体和 548 个有效传感器上，使用与上一轮相同的 96 个固定节点，对未来有效接触压力序列分别开展 5、10、20 帧 circular moving-block Bootstrap，每个 Recording/块长 200 次。先在 Recording 内汇总，再对每个物体的 3 个 Recording 取中位数，以 26 个物体作为主要汇总单位。

物体级中位数结果：块长 5/10/20 下，边排序 Spearman 分别为 0.9424/0.9193/0.8964；r≥0.7 正边 Jaccard 分别为 0.6047/0.5365/0.5000；平均绝对相关差（MAD）分别为 0.0390/0.0478/0.0539。块长变化带来系统差异，不能只选择短块下较高的稳定性数值。

时间自相关中位数显示 lag 1、5、10、20、40 帧的平均绝对 ACF 分别约为 0.751、0.435、0.241、0.125、0.072。短块 5 帧可能切断明显的局部时间依赖；20 帧是本轮候选中更保守的主报告设置，但更长滞后仍有弱相关，因此同时报告 5/10/20 敏感性范围，不宣称 20 帧完全消除了长程依赖。前 50/100/200 次重抽样的物体级中位数变化较小，200 次足以稳定本轮 Monte Carlo 汇总统计。

**标签冻结候选：** 主目标锁定为未来有效接触帧上的连续 Pearson 相关强度；r≥0.7 只作为辅助二元标签。Spearman 和 Ledoit-Wolf 继续作为估计方法对照。该决定是操作性统计标签定义，不代表因果或无误差物理真值。详细结果和限制见 docs/coactivation_block_sensitivity.md。

下一阶段转向物体级外层划分与 Support/Query 协议核验；随后先建立常数预测、历史相关、Logistic Regression 和 MLP 基线，再依据增量收益决定是否进入 GNN/MAML。



### 4.9 物体级外层划分与 Support / Query Episode 构建（已完成）

使用 pressure-only 的 metadata.mat 对 26 个非空物体和 78 个 Recording 进行重新分组。固定随机种子为 20261118，按物体划分为 Meta-train 18 个物体/54 个 Recording、Meta-validation 4 个物体/12 个 Recording、Meta-test 4 个物体/12 个 Recording。同一物体的三个 Recording 始终位于同一外层集合；官方 Recording 级 splitId 仅作为追溯字段，不用于外层划分。

固定对象集合：Meta-train 为 allen_key_set、ball、battery、board_eraser、cat、empty_can、gel、kiwano、lotion、mug、multimeter、safety_glasses、scissors、screw_driver、spoon、spray_can、tape、tea_box；Meta-validation 为 brain、chain、coin、pen；Meta-test 为 bracket、clip、full_can、stapler。

每个物体的三个 Recording 穷举全部 Support 组合：1-shot 为 1 个 Support + 2 个 Query，3 种组合；2-shot 为 2 个 Support + 1 个 Query，3 种组合。共生成 156 个 Episode：Meta-train 108、Meta-validation 24、Meta-test 24。156 个 Episode 是可复现的组合清单，不是 156 个独立任务；独立外层任务单位仍为物体，Meta-train 仅有 18 个任务，Meta-test 仅有 4 个物体。

真实数据核验：78 个 Recording 中，60 个最早 5 个有效接触帧在原始 frame 编号上连续，18 个不连续；输入时间跨度中位数 0.5460 秒，最大 5.3193 秒。每个 Recording 的未来有效接触帧数均值 1,009.54，中位数 910，范围 410–1,922。因此 K=5 必须表述为“最早 5 个有效帧”，不能误称为“连续 5 帧”。

自动审查已通过：26 个物体集合两两不重叠；78 个 Recording 全部且仅分配一次；同一物体 Recording 不跨集合；每个 Episode 的 Support / Query Recording 不重叠，且均属于同一物体和同一外层集合。单元测试 5/5 通过。详细协议、物体名单、局限和复现命令见 `docs/object_episode_protocol.md`。

当前统计限制：单次固定划分只有 4 个 Meta-test 物体。Support / Query 的穷举排列会重复使用 Recording，不能将 Episode 当成独立样本。测试结果必须先按物体汇总，并逐物体报告。后续可增加独立的重复物体级划分或外层交叉验证作为稳健性分析，但不能根据测试集表现调整当前固定划分。


### 4.10 统计预测基线实验（首轮已完成）

在固定 18/4/4 物体级划分和 1-shot/2-shot Support/Query 协议上，使用 pressure-only 数据完成常数预测、早期历史相关、Logistic Regression 和 MLP 基线。固定 96/548 个传感器子集，每个 Recording 4,560 条无向边；训练标准化器与全局模型仅使用 18 个 Meta-train 物体。连续未来 Pearson 为主目标，r≥0.7 为辅助分类目标。

Meta-test 四个物体汇总结果：常数预测 MAE=0.1314、RMSE=0.1718；早期五帧直接相关 MAE=0.4470、Spearman=0.0156；MLP 零样本 MAE=0.1100、RMSE=0.1457、Spearman=0.4003。MLP 零样本相对常数基线 MAE 下降约 16.3%。MLP 1-shot Support 适应 MAE=0.1130，2-shot 适应 MAE=0.1099，适应收益不稳定且幅度很小。

辅助分类中，Meta-test 正边比例约 0.71%。Logistic 零样本 AUROC=0.8907、AP=0.1078、F1=0.0498、Precision=0.0258、Recall=0.8639。MLP 连续预测分数的排序 AUROC=0.9107、AP=0.1736，但直接以 0.7 阈值转成类别时 F1=0，说明回归输出尚未校准为分类概率。

当前结论仅为首轮基线证据：MLP 提供了相对常数预测的预测增量；历史五帧 Pearson 不适合作为直接预测器；Support 适应尚无稳定收益。Meta-test 只有 4 个物体，且本轮只使用 96/548 个传感器，因此不能据此宣称最终泛化性能或 MAML 有效。完整方法、逐物体结果、限制和复现命令见 docs/coactivation_baseline_results.md。


### 4.11 重复物体级外层交叉验证（第八阶段）

为检验第七阶段结果是否依赖单次 18/4/4 物体划分，补充 5-fold × 5-repeat 的重复物体级分组交叉验证。每次重复中，26 个物体被均分为 5 折（测试折为 6/5/5/5/5 个物体），同一物体的三个 Recording 始终在同一折；每个物体每次重复恰好作为测试对象一次。共 25 次外层拟合，每个物体有 5 次 held-out 结果。

本轮冻结第七阶段 MLP / Logistic 超参数和 96/548 固定传感器子集，不用外层测试折调参。每折独立拟合标准化器与全局模型；在测试物体内部按 1-shot、2-shot Support/Query Episode 评估。先对同一物体的五次 held-out 结果求平均，再以 26 个物体为统计单位计算均值、标准差及物体级 Bootstrap 区间。Fold 间训练集重叠，因此 Fold 指标仅作描述，不作为独立重复推断。

重要边界：第七阶段固定测试物体已被报告；第八阶段会在其他重复中将这些物体纳入训练，因此第七阶段的四物体测试不能再被称为未触碰的独立最终测试集。第八阶段属于当前 26 个物体范围内的稳健性评估，不替代新增物体外部验证。完整协议见 docs/repeated_object_cv_protocol.md。



第八阶段真实运行结果（2026-11-19）：5-fold × 5-repeat，共 25 次外层拟合；26 个物体各被 held-out 五次。MLP 零样本 MAE=0.11716（物体 Bootstrap 95% CI：0.11188–0.12304），常数基线 MAE=0.13305（0.12674–0.13985）。配对 MAE 改善均值 0.01589（95% CI：0.01306–0.01872），相对下降 11.73%（9.84%–13.56%），26/26 个物体方向一致。1-shot Support 适应 MAE=0.12308，较零样本模型变差；2-shot 适应 MAE=0.11836，与零样本差值区间跨 0。当前证据支持 MLP 零样本的跨物体增量，但不支持 MAML/Support 适应增量。辅助 r≥0.7 正边比例约 0.567%，类别不平衡仍严重。详细结果见 docs/repeated_object_cv_results.md，汇总表位于 results/repeated_object_cv/。

**下一步决策：** 暂不进入 MAML；先做输入帧连续性与时间跨度敏感性分析，再决定是否扩展传感器规模或开展 GNN 空间结构增量实验。注意：原固定 18/4/4 的四物体测试集已在重复 CV 的其他重复中进入训练，不能再称为未触碰的独立最终测试集。


### 4.11 重复物体级外层划分稳健性验证（协议与脚本已提交，真实重复运行待数据执行）

为检验第七阶段单次 18/4/4 物体划分结果是否受物体组成影响，新增重复随机物体级留出实验。默认 20 次，每次将 26 个非空物体重新划分为 Meta-train 18、Meta-validation 4、Meta-test 4；划分种子从 20261118 起递增。传感器子集固定为同一组 96/548 个传感器（seed=20261116），模型结构、超参数、输入/标签定义均沿用第七阶段。每次仅在该次 Meta-train 拟合标准化器和全局模型，按物体汇总 1-shot / 2-shot 结果。

报告每次测试划分的物体平均指标、重复划分的均值/标准差、各物体作为测试对象时的表现稳定性，以及每次完整 26 物体分配清单。由于 20 次划分反复使用同一批 26 个物体，重复结果并非独立数据集；标准差仅描述划分敏感性，不作为独立样本标准误或常规显著性检验依据。

## 五、方法设计

### 5.1 总体技术路线

拟研究的模型由时序特征提取、关系结构建模、边预测和元学习适应四个部分组成：

1. 对早期压力观测进行清洗和特征构造；
2. 使用时序编码器提取传感器局部动态信息；
3. 将传感器间统计关系和空间拓扑信息纳入图结构建模；
4. 对传感器节点对进行协同边概率预测；
5. 以物体或抓取任务构造元学习任务，研究少样本适应能力。

整体流程如下：

```math
\text{早期触觉观测}
\rightarrow
\text{统计特征与时序编码}
\rightarrow
\text{关系/空间图建模}
\rightarrow
\text{边概率预测}
\rightarrow
\text{跨物体少样本适应}
```

### 5.2 时序特征提取

候选方案使用 Transformer 对每个传感器的早期压力序列进行编码，并考虑加入时间位置编码与传感器角色或位置编码。

需要特别注意：若输入仅为 5 帧，Transformer 的复杂时序建模能力未必能体现优势。因此应将其与简单统计特征、MLP 或轻量时序模型比较，不能预设 Transformer 必然有效。

传感器角色特征应仅由早期可用观测构造。任何从完整抓取序列计算得到的均值、峰值、偏度或其他画像，都不能作为早期预测输入。

### 5.3 统计关系特征

在预测时点可用的早期窗口内，构造传感器对的关系特征。候选特征包括：

- 早期窗口 Pearson 相关系数；
- 相关系数的方向与强度；
- 在定义明确的滞后范围内计算的互相关特征；
- 两个传感器的压力变化幅度或趋势差异。

短窗口下相关系数和最优滞后估计都可能不稳定，因此必须将其作为待检验的特征，而不是无误差的关系真值。滞后搜索范围、无效序列处理和特征标准化规则应在实验前固定。

### 5.4 空间结构与图神经网络

将传感器表示为图节点。若数据集提供可信的传感器空间坐标，可根据空间距离构造候选邻接关系；也可将预先定义的统计关系作为边特征或结构先验。

GCN 用于聚合邻域信息，学习传感器节点表示，再通过节点对表示进行边预测。

必须区分：

- **物理空间邻接：** 由传感器实际位置定义；
- **统计关系：** 由观测数据估计；
- **预测目标关系：** 由未来窗口标签定义。

三者不能混为一谈。若用未来标签构造图邻接并输入模型，会造成目标泄露。若使用训练集统计关系构图，应确保测试阶段不使用测试标签。

### 5.5 边预测模块

对传感器节点 $i$ 和 $j$ 的表示进行组合，输入 MLP 等边预测器，输出协同概率：

```math
\hat{p}_{ij}
=
\sigma\left(
f_{\theta}(h_i,h_j,e_{ij})
\right)
```

其中，$h_i$ 和 $h_j$ 为节点表示，$e_{ij}$ 为预测时点可获得的边特征，$\sigma$ 为 Sigmoid 函数。

损失函数可先采用二元交叉熵。若训练采样采用正负边平衡，需要记录采样比例，并在解释概率、校准指标及真实边密度时考虑抽样造成的分布变化。

### 5.6 元学习模块

候选方法为 MAML。将不同物体或符合任务定义的抓取任务视为不同任务，在训练任务上进行元训练，并在未见物体上使用少量 Support 样本适应，再在独立 Query 样本上评估。

元学习任务构造必须遵循：

- 训练阶段的任务仅来自训练物体；
- 验证和测试物体不参与元训练；
- Support 与 Query 不得由同一原始观测片段的重叠窗口泄露；
- 测试 Support 只用于规定的少样本适应，不得用于模型选择；
- 元训练、内循环和外循环的采样规则应固定并记录。

MAML 的二阶梯度计算可能带来较高的计算成本。应先通过小规模实验测量单个 Episode 耗时、显存占用和训练稳定性，再确定训练预算。若标准 MAML 成本过高，可将一阶近似作为单独对照，但应清楚标明方法差异。

## 六、实验设计

实验设计应围绕三个研究问题组织，不以堆叠模型数量为目标。

### 6.1 数据与标签审查实验

目的：确认数据质量、标签定义和样本构造是否可靠。

建议分析：

- 物体、试次和帧数分布；
- 传感器有效率、缺失和异常值；
- 压力值分布及不同物体之间的差异；
- 正负边比例及其在物体间的变化；
- 不同窗口长度和相关性阈值下的标签密度；
- 不同窗口或估计方法下的标签一致性。

### 6.2 基线模型比较

至少设置以下层次的基线：

| 类别 | 候选方法 | 目的 |
|---|---|---|
| 统计基线 | Pearson 相关性排序或阈值规则 | 判断简单相关特征本身的预测能力 |
| 传统统计学习 | Logistic Regression | 提供可解释的线性分类基线 |
| 机器学习基线 | Random Forest 或 XGBoost | 检验非线性表格特征的作用 |
| 神经网络基线 | MLP | 检验深度非线性映射的收益 |
| 图模型基线 | GCN + 边预测器 | 检验空间和关系结构建模的收益 |
| 元学习对照 | 普通训练/微调模型与 MAML | 检验任务级元学习的增量价值 |

所有基线应使用相同的数据划分、标签定义和测试 Episode。对模型容量差异较大的方法，应报告参数量或训练预算等必要信息。

### 6.3 核心模型实验

在基线完成后，评估完整候选模型。核心比较应回答：

- 完整模型是否优于简单统计基线；
- 是否优于不使用图结构的模型；
- 是否优于不进行元学习的同类模型；
- 提升是否在不同物体划分和随机种子下保持稳定；
- 性能提升是否具有实际意义，而不仅是数值上的微小差异。

### 6.4 消融实验

采用逐步增加信息来源的设计，避免一次性堆叠过多模块：

| 模型 | 输入/结构 | 主要检验内容 |
|---|---|---|
| A | 早期压力统计特征 | 节点自身信息基线 |
| B | A + 早期统计关系特征 | 统计关系的增量贡献 |
| C | A + 空间结构 | 空间先验的增量贡献 |
| D | A + 统计关系 + 空间结构 | 两类关系信息的联合贡献 |
| E | D + 时序编码器 | 时序编码的增量贡献 |
| F | E + 元学习 | 元学习的增量贡献 |

实际实现中应控制其他条件一致，并根据计算预算确定是否需要对所有组合进行完整交叉消融。消融结果应同时报告性能变化和不确定性。

### 6.5 敏感性分析

优先考察以下因素：

1. 输入窗口长度 $K$；
2. 标签窗口长度 $H$；
3. Pearson 标签阈值 (	au)；
4. Support 样本数量；
5. MAML 内循环步数；
6. 内循环与外循环学习率；
7. 空间邻接构造方式及邻居数量；
8. 传感器关系特征的选择。

敏感性分析应有明确研究目的，不必对所有超参数进行大规模网格搜索。超参数只能依据训练集和验证集确定，测试集只用于最终评估。

### 6.6 跨物体泛化实验

跨物体泛化是本文最重要的实验之一。

建议采用：

- 固定的物体级训练/验证/测试划分作为主实验；
- 多个随机物体级划分或重复分组验证作为稳定性分析；
- 按测试物体分别报告性能；
- 比较不同物体的性能差异；
- 比较不同 Support 规模下的适应效果；
- 对比元学习和普通微调在相同测试任务上的结果。

如果可用物体数量较少，应如实说明物体级统计不确定性较大，不能仅凭大量边样本得到过于乐观的显著性结论。

## 七、评价指标与统计分析

### 7.1 预测指标

| 指标 | 作用 | 注意事项 |
|---|---|---|
| ROC-AUC | 衡量正负边排序能力 | 不直接反映概率校准 |
| PR-AUC | 衡量正类识别表现 | 受正类比例影响 |
| Precision | 衡量预测正边的准确程度 | 依赖分类阈值 |
| Recall | 衡量真实正边的检出程度 | 依赖分类阈值 |
| F1 | 综合 Precision 与 Recall | 应说明阈值选择方式 |
| Brier Score | 衡量概率预测误差 | 需考虑采样分布和校准 |

如果训练或测试 Query 采用正负平衡采样，Precision、PR-AUC 和 Brier Score 不能直接解释为真实自然边分布下的应用性能。应尽可能在完整候选边集合上评估，或明确说明采样设计及其影响。

### 7.2 不确定性报告

建议至少报告：

- 多个随机种子或多个物体划分下的均值与标准差；
- 置信区间及其计算层级；
- 按物体分组的性能分布；
- 关键模型之间的配对性能差异；
- 不同物体上的失败案例。

由于边样本在同一物体和抓取片段内存在依赖，不能简单将所有边当作独立观测进行普通 Bootstrap。优先考虑物体层面或符合数据层级结构的分组重采样。若物体数量太少，置信区间本身也可能不稳定，应同时报告这一限制。

### 7.3 模型比较与显著性分析

模型比较应使用相同的测试物体、相同的 Episode 和相同的评估边集合，形成配对比较。

统计检验的选择应结合实际重复单位和样本量，避免把多个随机种子或同一物体产生的大量边简单视为独立实验单位。除显著性检验外，还应报告效应大小、区间估计和实际性能差异。

### 7.4 解释性分析

可通过特征消融、特征重要性、不同物体的关系图可视化等方式，研究模型主要依赖哪些信息。

解释性分析应区分预测关联和因果解释。模型认为某个特征重要，不代表该特征造成了传感器协同。

## 八、统计学研究价值与预期贡献

本文预期贡献应以能够由实验支持的内容为准，不将模型模块组合本身夸大为理论突破。

### 8.1 统计问题层面的贡献

围绕短窗口相关性估计和关系标签构造，分析观测长度、相关性阈值和估计方法对协同关系稳定性的影响，明确少样本条件下统计关系预测的适用边界。

### 8.2 方法应用层面的贡献

构建融合早期时序信息、传感器关系特征与空间结构信息的协同边预测框架，并研究元学习在跨物体少样本适应任务中的实际作用。

### 8.3 实证分析层面的贡献

通过基线比较、消融实验、敏感性分析和多物体划分验证，识别不同信息来源对预测性能的边际贡献，并分析复杂模型相对于简单统计方法的收益与代价。

### 8.4 潜在应用价值

研究结果可为机器人触觉感知中的传感器关系分析、触觉数据建模和少样本适应提供方法参考。但在没有实际机器人控制或应用实验之前，不将预测性能直接等同于抓取效果提升。

## 九、研究可行性、主要风险与应对方案

### 9.1 可行性判断

| 维度 | 当前判断 | 依据与限制 |
|---|---|---|
| 数据可行性 | 较高，待核验 | 已有公开数据方案；规模和字段需按实际文件核验 |
| 方法可行性 | 较高 | 相关方法成熟，但组合模型需验证必要性 |
| 计算可行性 | 中等偏高 | 主要成本来自 MAML 内循环和多任务重复训练 |
| 实验可行性 | 较高 | 可开展基线、消融、敏感性和跨物体验证 |
| 统计推断可行性 | 需重点控制 | 独立物体数量有限，数据存在层级依赖 |
| 创新性 | 中等，需凝练 | 主要潜力来自问题设定、统计分析和系统实证，而非模型拼接 |

### 9.2 主要风险

**风险一：独立物体数量有限。**  
即使帧数和边数量较大，真正用于跨物体泛化的独立对象仍然有限。应通过多个物体划分、逐物体报告和分组不确定性分析控制结论强度。

**风险二：短窗口相关性估计不稳定。**  
5 帧输入和 10 帧标签窗口可能产生较大的估计误差。应开展窗口长度、阈值和估计方法的敏感性分析，并记录无效相关系数比例。

**风险三：输入特征与标签语义不一致。**  
正相关、绝对相关和滞后相关代表不同统计关系。应统一定义、特征和解释，不能将负相关自动解释为正向协同。

**风险四：未来信息泄露。**  
完整抓取序列统计量、测试物体统计信息或未来标签参与图构造，都可能导致泄露。必须建立特征时间边界和数据划分检查。

**风险五：复杂模型不一定优于简单基线。**  
若 Pearson、Logistic Regression 或 MLP 已经表现良好，复杂模型可能没有足够增量收益。应把模型简化和负面结果分析纳入研究方案。

**风险六：元学习训练成本较高。**  
先开展小规模性能测试，评估 MAML 的耗时、显存和收敛稳定性；根据结果控制任务数和内循环步数。

**风险七：测试集物体过少。**  
单次 18/4/4 划分可能对测试结果产生较大影响。应增加合理的重复物体划分，并谨慎解释置信区间和显著性检验。

### 9.3 风险控制原则

- 不以帧数、窗口数或边数替代独立物体数量；
- 不使用未来数据构造输入；
- 不把统计相关性解释为因果关系；
- 不预设复杂模型优于简单模型；
- 不以单次划分或单个随机种子得出普遍性结论；
- 不在测试集上调参；
- 对所有预处理、采样、标签和划分规则进行记录。

## 十一、预期实施流程与阶段性交付物

研究按以下顺序推进。每一阶段完成后，应保留代码、配置、数据摘要或实验记录，确保结果可追溯。

| 阶段 | 主要工作 | 阶段性交付物 |
|---|---|---|
| 1. 数据核验 | 获取数据、核对来源许可、检查字段和分组信息 | 数据说明、数据审查报告 |
| 2. 数据探索 | 缺失值、异常值、物体分布、压力分布和相关性分析 | EDA 脚本、统计图表 |
| 3. 任务构建 | 确定窗口、标签、边采样和物体划分 | 可复现的数据构造模块 |
| 4. 统计基线 | Pearson、Logistic Regression 等 | 基线结果与分析 |
| 5. 模型实现 | 时序编码、图建模和边预测 | 可训练的基础模型 |
| 6. 元学习实现 | 任务采样、内外循环和少样本适应 | MAML 训练与测试模块 |
| 7. 主实验 | 统一测试协议，比较各类模型 | 主实验结果表 |
| 8. 补充分析 | 消融、敏感性、分组不确定性与案例分析 | 补充实验结果 |
| 9. 论文撰写 | 形成方法、实验、讨论与结论 | 学位论文初稿和定稿 |

### 阶段完成标准

- **数据核验完成：** 数据来源、许可、字段、物体和试次分组均有记录。
- **任务构建完成：** 输入与标签时间边界清晰，数据划分不存在跨集合泄露。
- **基线完成：** 至少有可复现的统计基线和传统机器学习基线。
- **模型完成：** 模型可训练、可验证、可保存配置并复现实验。
- **主实验完成：** 在未见物体上按预先确定的协议评估。
- **统计分析完成：** 对物体差异、随机划分波动和关键性能差异进行分析。
- **论文完成：** 研究问题、方法、实验结果和结论相互对应，所有结论均有数据支持。

## 十二、硕士学位论文要求下的自我评估

本研究的目标不是单纯实现一个深度学习系统，而是形成一项具有明确统计问题、规范实验设计和可信实证结论的研究。

从硕士论文角度，重点需要满足：

1. **问题明确：** 研究对象、预测目标和适用条件清楚；
2. **方法合理：** 统计定义、特征构造和模型方法与研究问题一致；
3. **实验严谨：** 数据划分、对照实验和信息泄露控制规范；
4. **分析充分：** 不仅报告指标，还分析不确定性、物体差异和方法适用边界；
5. **贡献真实：** 说明相对于已有方法的实际增量，不夸大模型组合的创新程度；
6. **可复现：** 代码、配置、数据处理规则和实验结果能够追溯。

**当前综合判断：** 课题具有开展统计学硕士论文研究的潜力，数据和方法路线总体可实施，预期工作量较为充足。但目前理论创新程度尚需凝练，独立物体数量有限、短窗口相关性估计不稳定和模型组合必要性尚未验证，是影响最终论文质量的主要问题。

因此，后续研究应优先完成数据审查、标签稳定性分析和统计基线实验，再决定是否保留全部复杂模型模块。是否达到学位授予要求，最终仍以所在学院现行培养方案、学位论文规范和评审要求为准。
