# 论文预期流程与研究方案

## 一、研究题目与定位

### 1.1 拟定题目

**基于元学习与图神经网络的触觉传感器协同激活预测研究**

英文题目暂拟为：

*Meta-Learning and Graph Neural Networks for Predicting Tactile Sensor Co-activation*

题目可在完成数据核验、明确协同关系定义及确定最终方法后进一步调整。

### 1.2 学科定位

本研究拟以统计学硕士学位论文的要求组织工作，研究重点不只是搭建一个由 Transformer、GCN 和 MAML 组成的复杂模型，而是围绕少样本条件下的触觉传感器协同关系估计与预测，开展统计定义、结构化建模、跨物体验证和不确定性分析。

研究将综合使用多变量时间序列分析、相关性估计、图结构建模、概率预测、少样本学习及统计推断等方法。深度学习模型是解决研究问题的工具，而不是研究目的本身。

### 1.3 研究边界

当前研究聚焦于**触觉传感器之间协同关系的预测**。现阶段不直接研究机器人控制策略，也不声称已经实现抓取稳定性提升、实时控制或工业部署。上述方向仅作为潜在应用背景，除非后续增加相应实验，否则不作为本文已验证的结论。

本文所称“协同激活”首先是一个可操作化的统计关系概念。若采用相关系数阈值构造标签，预测对象应准确表述为“基于指定时间窗口和阈值定义的统计协同关系”，不能直接将其解释为因果关系或真实物理协作机制。

## 二、研究背景与核心问题

触觉传感系统通常由多个空间分布的传感器构成。物体接触和抓取过程中，各传感器会产生随时间变化的压力响应。不同传感器的响应可能表现出同步变化、空间关联或一定的时间依赖。

在实际感知场景中，面对一个此前未见过的物体，系统可能只能获得有限的早期触觉观测。如何利用这些有限观测，预测该物体后续阶段不同传感器之间可能形成的协同关系，是一个具有研究价值的问题。

与普通的单变量预测或分类不同，本研究的预测对象是传感器两两之间的关系结构；与传统的同分布训练测试划分不同，本研究重点考察模型从已见物体迁移到未见物体的能力。

### 2.1 核心科学问题

**在少样本条件下，如何利用早期触觉观测及有限的统计和空间结构信息，稳定地预测未见物体上的传感器协同关系？**

### 2.2 拟回答的三个研究问题

- **RQ1：协同关系能否被可靠估计？** 短时间窗口下，传感器相关性及由此构造的协同标签有多大不确定性？窗口长度、相关性估计方法和阈值会如何影响关系结构？
- **RQ2：哪些信息有助于预测协同关系？** 传感器自身的时序统计特征、传感器之间的统计关系以及空间结构信息，分别能带来多少增量预测价值？
- **RQ3：元学习能否改善跨物体少样本泛化？** 与普通监督学习及其他基线相比，元学习是否能在未见物体上带来稳定、可重复且具有实际意义的性能提升？这种提升是否依赖物体类型、Support 样本量或任务划分？

### 2.3 研究假设（待检验）

- H1：仅使用早期触觉观测构造的统计特征，对后续窗口定义的协同关系具有一定预测能力。
- H2：在传感器自身特征之外加入传感器间关系信息和空间结构信息，可能改善协同边预测。
- H3：当训练物体与测试物体存在任务层面的差异时，元学习可能比不进行任务级适应的普通监督学习更有利于少样本泛化。
- H4：不同物体、不同观测窗口和不同协同关系定义下，模型表现可能存在明显差异。

上述假设均需由实验检验，不预设其成立。

## 三、数据基础与数据审查

### 3.1 当前数据方案

当前研究方案拟使用 MIT HumanGrasp（STAG）相关触觉数据。前期方案记录的数据概况为：

- 约 26 种日常物体；
- 约 548 个有效压力传感器；
- 约 13.5 万帧压力数据；
- 单帧压力观测约为 548 维。

**以上数字是当前方案中的数据描述，正式研究前必须依据实际下载的数据、数据集论文及官方说明逐项核验。** 在完成核验前，不应将这些数字作为已审计的数据事实写入论文最终稿。

### 3.2 数据审查任务

正式建模前，先形成数据审查记录，至少包括：

1. 数据集官方名称、版本、来源、引用方式及许可条件；
2. 物体类别数量、每类物体对应的抓取片段数量；
3. 传感器数量、传感器编号、空间坐标及有效性标记；
4. 时间戳、采样频率、缺失值、异常值和重复记录；
5. 每个抓取片段的起止位置及物体、试次等分组标识；
6. 不同物体和抓取片段的数据长度分布；
7. 数据预处理和标签构造所需字段是否真实存在。

数据审查结果应保存为可复现的统计摘要，不应只在代码中隐式处理。

### 3.3 样本独立性与划分原则

约 13.5 万帧不等于 13.5 万个独立样本。相邻帧、同一抓取片段的滑动窗口，以及同一物体产生的多个 Episode 可能具有较强依赖性。

研究目标是跨物体泛化，因此主实验应优先按照**物体分组**划分训练集、验证集和测试集，保证测试物体不参与模型训练、特征标准化参数估计、阈值调节和模型选择。

初始方案中的 70%/15%/15% 物体划分可作为候选方案，但需要结合实际物体数量确定整数分配。若总计为 26 个物体，划分大致为 18/4/4；这意味着测试物体数量较少，单次划分的结果可能对个别物体较敏感。因此还应开展多个随机物体划分或重复分组验证，并明确报告每次划分包含的物体。

若数据中存在同一物体的多个独立抓取试次，可在物体级划分之外进一步保留试次分组信息，用于检查同物体内的重复观测依赖，但不能以试次级划分替代跨物体测试。

### 3.4 数据泄露控制

所有模型输入、统计画像、图结构先验、标准化参数和特征选择结果，都必须仅使用训练阶段可用的数据以及预测时点之前已经观测到的信息。

若任务定义为使用前 5 帧预测后续 10 帧，则：

- 输入特征只能由前 5 帧构造；
- 标签只能由后续 10 帧按预先规定的规则构造；
- 不得使用完整抓取序列的均值、峰值、偏度等统计量作为早期预测输入；
- 标准化参数只能由训练数据估计；
- 测试物体不能参与超参数选择、阈值选择或模型训练；
- 同一抓取片段产生的重叠窗口不能跨越训练、验证和测试边界。

## 四、任务定义与统计标签构造

### 4.1 预测任务

设一个抓取片段中有 (N) 个有效传感器。第 (i) 个传感器在时刻 (t) 的压力观测记为 (x_i(t))。

在当前方案中，拟采用早期 (K) 帧作为输入，后续 (H) 帧作为标签构造窗口。前期方案的候选设置为 (K=5)、(H=10)，这两个参数应在数据审查和敏感性分析后最终确定。

模型输入为早期观测及其派生特征，输出为传感器对 ((i,j)) 的协同概率：

[
hat p_{ij} = P(Y_{ij}=1mid mathcal{F}_{mathrm{early}})
]

其中，(mathcal{F}_{mathrm{early}}) 表示预测时点可获得的早期观测信息。

### 4.2 协同关系的操作性定义

一个候选定义是：根据后续 (H) 帧中两个传感器压力序列的 Pearson 相关系数构造二元标签：

[

=

left(

]

[

]

其中，前期方案候选阈值为 (	au=0.7)。

这一标签只表示在指定未来窗口和阈值下的正向线性相关关系，不表示因果关系，也不必然等价于生理或物理意义上的协同机制。

### 4.3 标签定义需要解决的问题

1. **窗口长度问题：** 仅使用 10 帧估计相关系数可能产生较大的抽样不确定性，需要改变 (H) 并考察标签稳定性。
2. **阈值问题：** (	au=0.7) 是候选设定，不应只报告单一阈值结果；需要开展阈值敏感性分析。
3. **方向问题：** 正相关 (r_{ij}geq 0.7) 与绝对相关 (|r_{ij}|geq 0.7) 定义不同。若研究正向同步激活，标签、输入特征和解释必须保持一致；负相关不能被绝对值特征无差别地视为正向协同。
4. **常数序列问题：** 当某个窗口内传感器压力没有变化时，相关系数可能无法定义。必须预先规定无效边的处理规则，并报告无效比例。
5. **类别不平衡问题：** 应先统计完整候选边集合中的正负边比例，再决定训练采样策略。若为计算方便进行正负平衡采样，评估时应同时提供能够反映自然类别比例的结果或明确说明采样分布的影响。
6. **标签噪声问题：** 需要评估不同窗口、试次和估计方法下标签的一致性，不应把由短窗口估计产生的二元标签当作无误差真值。

### 4.4 备选统计定义

可将以下定义作为稳健性分析，而不是在未验证前全部纳入主模型：

- Spearman 秩相关：检验单调关系下的稳健性；
- 收缩相关估计：在样本较短时探索对相关矩阵的正则化；
- 不同时间窗口的 Pearson 相关：检验时间尺度影响；
- 保留正负方向的相关特征：避免绝对相关造成语义混淆。

最终主标签应选择一个定义清晰、可重复、与研究问题一致的方案，其余定义用于敏感性分析。

## 五、方法设计

### 5.1 总体技术路线

拟研究的模型由时序特征提取、关系结构建模、边预测和元学习适应四个部分组成：

1. 对早期压力观测进行清洗和特征构造；
2. 使用时序编码器提取传感器局部动态信息；
3. 将传感器间统计关系和空间拓扑信息纳入图结构建模；
4. 对传感器节点对进行协同边概率预测；
5. 以物体或抓取任务构造元学习任务，研究少样本适应能力。

整体流程如下：

[
	ext{早期触觉观测}
ightarrow
	ext{统计特征与时序编码}
ightarrow
	ext{关系/空间图建模}
ightarrow
	ext{边概率预测}
ightarrow
	ext{跨物体少样本适应}
]

### 5.2 时序特征提取

候选方案使用 Transformer 对每个传感器的早期压力序列进行编码，并考虑加入时间位置编码与传感器角色或位置编码。

需要特别注意：若输入仅为 5 帧，Transformer 的复杂时序建模能力未必能体现优势。因此应将其与简单统计特征、MLP 或轻量时序模型比较，不能预设 Transformer 必然有效。

传感器角色特征应仅由早期可用观测构造。任何从完整抓取序列计算得到的均值、峰值、偏度或其他画像，都不能作为早期预测输入。

### 5.3 统计关系特征

在预测时点可用的早期窗口内，构造传感器对的关系特征。候选特征包括：

- 早期窗口 Pearson 相关系数；
- 相关系数的方向与强度；
- 在定义明确的滞后范围内计算的互相关特征；
- 两个传感器的压力变化幅度或趋势差异。

短窗口下相关系数和最优滞后估计都可能不稳定，因此必须将其作为待检验的特征，而不是无误差的关系真值。滞后搜索范围、无效序列处理和特征标准化规则应在实验前固定。

### 5.4 空间结构与图神经网络

将传感器表示为图节点。若数据集提供可信的传感器空间坐标，可根据空间距离构造候选邻接关系；也可将预先定义的统计关系作为边特征或结构先验。

GCN 用于聚合邻域信息，学习传感器节点表示，再通过节点对表示进行边预测。

必须区分：

- **物理空间邻接：** 由传感器实际位置定义；
- **统计关系：** 由观测数据估计；
- **预测目标关系：** 由未来窗口标签定义。

三者不能混为一谈。若用未来标签构造图邻接并输入模型，会造成目标泄露。若使用训练集统计关系构图，应确保测试阶段不使用测试标签。

### 5.5 边预测模块

对传感器节点 (i,j) 的表示进行组合，输入 MLP 等边预测器，输出协同概率：

[
hat p_{ij}=sigmaleft(f_	heta(h_i,h_j,e_{ij})ight)
]

其中，(h_i,h_j) 为节点表示，(e_{ij}) 为预测时点可获得的边特征，(sigma) 为 Sigmoid 函数。

损失函数可先采用二元交叉熵。若训练采样采用正负边平衡，需要记录采样比例，并在解释概率、校准指标及真实边密度时考虑抽样造成的分布变化。

### 5.6 元学习模块

候选方法为 MAML。将不同物体或符合任务定义的抓取任务视为不同任务，在训练任务上进行元训练，并在未见物体上使用少量 Support 样本适应，再在独立 Query 样本上评估。

元学习任务构造必须遵循：

- 训练阶段的任务仅来自训练物体；
- 验证和测试物体不参与元训练；
- Support 与 Query 不得由同一原始观测片段的重叠窗口泄露；
- 测试 Support 只用于规定的少样本适应，不得用于模型选择；
- 元训练、内循环和外循环的采样规则应固定并记录。

MAML 的二阶梯度计算可能带来较高的计算成本。应先通过小规模实验测量单个 Episode 耗时、显存占用和训练稳定性，再确定训练预算。若标准 MAML 成本过高，可将一阶近似作为单独对照，但应清楚标明方法差异。

## 六、实验设计

实验设计应围绕三个研究问题组织，不以堆叠模型数量为目标。

### 6.1 数据与标签审查实验

目的：确认数据质量、标签定义和样本构造是否可靠。

建议分析：

- 物体、试次和帧数分布；
- 传感器有效率、缺失和异常值；
- 压力值分布及不同物体之间的差异；
- 正负边比例及其在物体间的变化；
- 不同窗口长度和相关性阈值下的标签密度；
- 不同窗口或估计方法下的标签一致性。

### 6.2 基线模型比较

至少设置以下层次的基线：

| 类别 | 候选方法 | 目的 |
|---|---|---|
| 统计基线 | Pearson 相关性排序或阈值规则 | 判断简单相关特征本身的预测能力 |
| 传统统计学习 | Logistic Regression | 提供可解释的线性分类基线 |
| 机器学习基线 | Random Forest 或 XGBoost | 检验非线性表格特征的作用 |
| 神经网络基线 | MLP | 检验深度非线性映射的收益 |
| 图模型基线 | GCN + 边预测器 | 检验空间和关系结构建模的收益 |
| 元学习对照 | 普通训练/微调模型与 MAML | 检验任务级元学习的增量价值 |

所有基线应使用相同的数据划分、标签定义和测试 Episode。对模型容量差异较大的方法，应报告参数量或训练预算等必要信息。

### 6.3 核心模型实验

在基线完成后，评估完整候选模型。核心比较应回答：

- 完整模型是否优于简单统计基线；
- 是否优于不使用图结构的模型；
- 是否优于不进行元学习的同类模型；
- 提升是否在不同物体划分和随机种子下保持稳定；
- 性能提升是否具有实际意义，而不仅是数值上的微小差异。

### 6.4 消融实验

采用逐步增加信息来源的设计，避免一次性堆叠过多模块：

| 模型 | 输入/结构 | 主要检验内容 |
|---|---|---|
| A | 早期压力统计特征 | 节点自身信息基线 |
| B | A + 早期统计关系特征 | 统计关系的增量贡献 |
| C | A + 空间结构 | 空间先验的增量贡献 |
| D | A + 统计关系 + 空间结构 | 两类关系信息的联合贡献 |
| E | D + 时序编码器 | 时序编码的增量贡献 |
| F | E + 元学习 | 元学习的增量贡献 |

实际实现中应控制其他条件一致，并根据计算预算确定是否需要对所有组合进行完整交叉消融。消融结果应同时报告性能变化和不确定性。

### 6.5 敏感性分析

优先考察以下因素：

1. 输入窗口长度 (K)；
2. 标签窗口长度 (H)；
3. Pearson 标签阈值 (	au)；
4. Support 样本数量；
5. MAML 内循环步数；
6. 内循环与外循环学习率；
7. 空间邻接构造方式及邻居数量；
8. 传感器关系特征的选择。

敏感性分析应有明确研究目的，不必对所有超参数进行大规模网格搜索。超参数只能依据训练集和验证集确定，测试集只用于最终评估。

### 6.6 跨物体泛化实验

跨物体泛化是本文最重要的实验之一。

建议采用：

- 固定的物体级训练/验证/测试划分作为主实验；
- 多个随机物体级划分或重复分组验证作为稳定性分析；
- 按测试物体分别报告性能；
- 比较不同物体的性能差异；
- 比较不同 Support 规模下的适应效果；
- 对比元学习和普通微调在相同测试任务上的结果。

如果可用物体数量较少，应如实说明物体级统计不确定性较大，不能仅凭大量边样本得到过于乐观的显著性结论。

---

## 七、评价指标与统计分析

### 7.1 预测指标

| 指标 | 作用 | 注意事项 |
|---|---|---|
| ROC-AUC | 衡量正负边排序能力 | 不直接反映概率校准 |
| PR-AUC | 衡量正类识别表现 | 受正类比例影响 |
| Precision | 衡量预测正边的准确程度 | 依赖分类阈值 |
| Recall | 衡量真实正边的检出程度 | 依赖分类阈值 |
| F1 | 综合 Precision 与 Recall | 应说明阈值选择方式 |
| Brier Score | 衡量概率预测误差 | 需考虑采样分布和校准 |

如果训练或测试 Query 采用正负平衡采样，Precision、PR-AUC 和 Brier Score 不能直接解释为真实自然边分布下的应用性能。应尽可能在完整候选边集合上评估，或明确说明采样设计及其影响。

### 7.2 不确定性报告

建议至少报告：

- 多个随机种子或多个物体划分下的均值与标准差；
- 置信区间及其计算层级；
- 按物体分组的性能分布；
- 关键模型之间的配对性能差异；
- 不同物体上的失败案例。

由于边样本在同一物体和抓取片段内存在依赖，不能简单将所有边当作独立观测进行普通 Bootstrap。优先考虑物体层面或符合数据层级结构的分组重采样。若物体数量太少，置信区间本身也可能不稳定，应同时报告这一限制。

### 7.3 模型比较与显著性分析

模型比较应使用相同的测试物体、相同的 Episode 和相同的评估边集合，形成配对比较。

统计检验的选择应结合实际重复单位和样本量，避免把多个随机种子或同一物体产生的大量边简单视为独立实验单位。除显著性检验外，还应报告效应大小、区间估计和实际性能差异。

### 7.4 解释性分析

可通过特征消融、特征重要性、不同物体的关系图可视化等方式，研究模型主要依赖哪些信息。

解释性分析应区分预测关联和因果解释。模型认为某个特征重要，不代表该特征造成了传感器协同。

## 八、统计学研究价值与预期贡献

本文预期贡献应以能够由实验支持的内容为准，不将模型模块组合本身夸大为理论突破。

### 8.1 统计问题层面的贡献

围绕短窗口相关性估计和关系标签构造，分析观测长度、相关性阈值和估计方法对协同关系稳定性的影响，明确少样本条件下统计关系预测的适用边界。

### 8.2 方法应用层面的贡献

构建融合早期时序信息、传感器关系特征与空间结构信息的协同边预测框架，并研究元学习在跨物体少样本适应任务中的实际作用。

### 8.3 实证分析层面的贡献

通过基线比较、消融实验、敏感性分析和多物体划分验证，识别不同信息来源对预测性能的边际贡献，并分析复杂模型相对于简单统计方法的收益与代价。

### 8.4 潜在应用价值

研究结果可为机器人触觉感知中的传感器关系分析、触觉数据建模和少样本适应提供方法参考。但在没有实际机器人控制或应用实验之前，不将预测性能直接等同于抓取效果提升。

## 九、研究可行性、主要风险与应对方案

### 9.1 可行性判断

| 维度 | 当前判断 | 依据与限制 |
|---|---|---|
| 数据可行性 | 较高，待核验 | 已有公开数据方案；规模和字段需按实际文件核验 |
| 方法可行性 | 较高 | 相关方法成熟，但组合模型需验证必要性 |
| 计算可行性 | 中等偏高 | 主要成本来自 MAML 内循环和多任务重复训练 |
| 实验可行性 | 较高 | 可开展基线、消融、敏感性和跨物体验证 |
| 统计推断可行性 | 需重点控制 | 独立物体数量有限，数据存在层级依赖 |
| 创新性 | 中等，需凝练 | 主要潜力来自问题设定、统计分析和系统实证，而非模型拼接 |

### 9.2 主要风险

**风险一：独立物体数量有限。**  
即使帧数和边数量较大，真正用于跨物体泛化的独立对象仍然有限。应通过多个物体划分、逐物体报告和分组不确定性分析控制结论强度。

**风险二：短窗口相关性估计不稳定。**  
5 帧输入和 10 帧标签窗口可能产生较大的估计误差。应开展窗口长度、阈值和估计方法的敏感性分析，并记录无效相关系数比例。

**风险三：输入特征与标签语义不一致。**  
正相关、绝对相关和滞后相关代表不同统计关系。应统一定义、特征和解释，不能将负相关自动解释为正向协同。

**风险四：未来信息泄露。**  
完整抓取序列统计量、测试物体统计信息或未来标签参与图构造，都可能导致泄露。必须建立特征时间边界和数据划分检查。

**风险五：复杂模型不一定优于简单基线。**  
若 Pearson、Logistic Regression 或 MLP 已经表现良好，复杂模型可能没有足够增量收益。应把模型简化和负面结果分析纳入研究方案。

**风险六：元学习训练成本较高。**  
先开展小规模性能测试，评估 MAML 的耗时、显存和收敛稳定性；根据结果控制任务数和内循环步数。

**风险七：测试集物体过少。**  
单次 18/4/4 划分可能对测试结果产生较大影响。应增加合理的重复物体划分，并谨慎解释置信区间和显著性检验。

### 9.3 风险控制原则

- 不以帧数、窗口数或边数替代独立物体数量；
- 不使用未来数据构造输入；
- 不把统计相关性解释为因果关系；
- 不预设复杂模型优于简单模型；
- 不以单次划分或单个随机种子得出普遍性结论；
- 不在测试集上调参；
- 对所有预处理、采样、标签和划分规则进行记录。

## 十一、预期实施流程与阶段性交付物

研究按以下顺序推进。每一阶段完成后，应保留代码、配置、数据摘要或实验记录，确保结果可追溯。

| 阶段 | 主要工作 | 阶段性交付物 |
|---|---|---|
| 1. 数据核验 | 获取数据、核对来源许可、检查字段和分组信息 | 数据说明、数据审查报告 |
| 2. 数据探索 | 缺失值、异常值、物体分布、压力分布和相关性分析 | EDA 脚本、统计图表 |
| 3. 任务构建 | 确定窗口、标签、边采样和物体划分 | 可复现的数据构造模块 |
| 4. 统计基线 | Pearson、Logistic Regression 等 | 基线结果与分析 |
| 5. 模型实现 | 时序编码、图建模和边预测 | 可训练的基础模型 |
| 6. 元学习实现 | 任务采样、内外循环和少样本适应 | MAML 训练与测试模块 |
| 7. 主实验 | 统一测试协议，比较各类模型 | 主实验结果表 |
| 8. 补充分析 | 消融、敏感性、分组不确定性与案例分析 | 补充实验结果 |
| 9. 论文撰写 | 形成方法、实验、讨论与结论 | 学位论文初稿和定稿 |

### 阶段完成标准

- **数据核验完成：** 数据来源、许可、字段、物体和试次分组均有记录。
- **任务构建完成：** 输入与标签时间边界清晰，数据划分不存在跨集合泄露。
- **基线完成：** 至少有可复现的统计基线和传统机器学习基线。
- **模型完成：** 模型可训练、可验证、可保存配置并复现实验。
- **主实验完成：** 在未见物体上按预先确定的协议评估。
- **统计分析完成：** 对物体差异、随机划分波动和关键性能差异进行分析。
- **论文完成：** 研究问题、方法、实验结果和结论相互对应，所有结论均有数据支持。

## 十二、硕士学位论文要求下的自我评估

本研究的目标不是单纯实现一个深度学习系统，而是形成一项具有明确统计问题、规范实验设计和可信实证结论的研究。

从硕士论文角度，重点需要满足：

1. **问题明确：** 研究对象、预测目标和适用条件清楚；
2. **方法合理：** 统计定义、特征构造和模型方法与研究问题一致；
3. **实验严谨：** 数据划分、对照实验和信息泄露控制规范；
4. **分析充分：** 不仅报告指标，还分析不确定性、物体差异和方法适用边界；
5. **贡献真实：** 说明相对于已有方法的实际增量，不夸大模型组合的创新程度；
6. **可复现：** 代码、配置、数据处理规则和实验结果能够追溯。

**当前综合判断：** 课题具有开展统计学硕士论文研究的潜力，数据和方法路线总体可实施，预期工作量较为充足。但目前理论创新程度尚需凝练，独立物体数量有限、短窗口相关性估计不稳定和模型组合必要性尚未验证，是影响最终论文质量的主要问题。

因此，后续研究应优先完成数据审查、标签稳定性分析和统计基线实验，再决定是否保留全部复杂模型模块。是否达到学位授予要求，最终仍以所在学院现行培养方案、学位论文规范和评审要求为准。
