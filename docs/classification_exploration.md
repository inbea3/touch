# 早期触觉物体分类：独立探索路线

该模块研究：给定抓取片段早期连续 K 帧压力图，识别当前物体类别。它是独立探索，不替代当前正式研究方案“触觉传感器协同激活预测”。

| 维度 | 主研究路线 | 本探索路线 |
|---|---|---|
| 预测对象 | 传感器对的未来协同关系 | 当前窗口的物体类别 |
| 标签 | 未来窗口相关性阈值 | object_id |
| 统计单位 | 物体/抓取任务及传感器边 | Recording/抓取窗口 |
| 主要风险 | 未来标签泄漏、跨物体任务泄漏 | 重叠窗口、同 Recording 泄漏 |
| 指标 | AUC、PR-AUC、校准与不确定性 | Accuracy、Macro-F1 |

当前默认按类别分层、按 Recording 分组，因此评估的是“已知类别的新 Recording 识别”，不是“训练中未出现过的新物体类别识别”。真正的未见类别少样本学习需要按类别划分 meta-train/meta-validation/meta-test，并确保每个测试类别有足够独立 Recording 提供 Support 和 Query。
