# G2-R2：完整548节点图模型训练收敛与内部验证协议

**协议冻结日期：2026-11-22**  
**状态：** 正式运行中；结果尚未解盲汇总。  
**数据边界：** STAG classification pressure-only；不读取或使用视频、图像、视觉标注。

## 1. 研究问题

检验G2-R1在固定5 epochs下观察到的空间图增量，是否受到训练预算不足影响；在不使用外层测试物体选择epoch的前提下，比较Node-MLP与完整548节点k=4/k=6/k=8空间图模型。

## 2. 数据与任务

- 原始压力张量：135,187 × 32 × 32。
- G0冻结的548个活动传感器、26个非空物体、78条非空Recording。
- 每条Recording有149,878个无序传感器对。
- 输入为按时间排序最早5个hasValidLabel=True压力帧。
- 目标为其后全部有效压力帧计算的Pearson相关系数。
- 压力归一化：clip((pressure-500)/150,0,1)。
- 节点特征与G2一致：8个早期压力统计量和归一化x/y坐标，共10维。
- 输入metadata SHA-256：19062ed3415df6e21ae055c5149315a5350652a27d59ab55fed74e395f2f1378。

## 3. 外层评估

- 物体级5-fold grouped CV。
- Split seeds：20261119、20261120、20261121。
- 共15个外层fold；同一物体的3条Recording始终在同一折。
- 外层测试物体只用于最终指标计算，不参与内部验证、epoch选择或标准化拟合。

## 4. 内部验证与epoch选择

每个外层fold中，从外层训练物体中按固定随机种子抽取20%作为内部验证物体，至少4个物体；其余物体用于内部训练。Support/validation单位为物体，Recording不跨集合。

- 内部验证只训练预先指定的Node-MLP参考模型。
- 每轮在固定的内部验证Recording pair子样本上计算Recording MAE；先对同一物体的Recording求平均，再对内部验证物体等权平均。
- 每条验证Recording固定抽取8,192个有效传感器对，整个训练过程中不改变样本。
- 最低内部验证物体宏平均MAE对应的epoch为共同epoch；patience=6，min_delta=1e-5，最大训练预算30 epochs。
- 选择出的共同epoch用于四个候选模型，避免不同架构各自使用不同训练轮数而形成预算不公平。
- 若最优epoch出现在30轮上限，标记为达到预算上限；不得声称已收敛。

## 5. 训练样本调度与公平性

候选模型：Node-MLP、Spatial-GNN k4、Spatial-GNN k6、Spatial-GNN k8。

为减少每轮重复编码同一物体的多个Recording，采用物体平衡轮换采样：
- 每个训练epoch，每个物体抽取一条Recording；
- 每个物体的3条Recording按确定性轮换顺序覆盖；
- 每条被选Recording均匀无放回抽取12,288个有效pair；
- 因每物体每轮有一条Recording，故每物体每轮抽样12,288个pair，与G2每物体每轮3条Recording各抽4,096个pair的总pair预算相同；
- 每个候选模型共享同一epoch的Recording顺序和pair索引。
- 每4条Recording组成一个训练batch，损失对batch内抽样pair取均值。

优化器：AdamW，学习率0.0005，weight decay 0.001。所有候选模型使用相同NodeRelNet可训练结构和初始化；唯一模型条件差异为归一化邻接矩阵。

## 6. 外层重训练与测试

完成内部epoch选择后：
1. StandardScaler在全部外层训练Recording上重新拟合；
2. 四个候选模型分别在全部外层训练物体上从相同初始化重训练；
3. 四个候选模型均使用内部验证选出的共同epoch；
4. 外层测试Recording的全部149,878个有效pair均参与评估；
5. 主要指标MAE，辅助指标RMSE和Spearman；
6. 先对Recording在物体内求平均，再对外层测试物体等权汇总。

四个候选模型均为预先指定比较对象。不得根据外层测试结果再选择最终图尺度；外层比较用于报告各候选模型的泛化表现，图尺度选择仍需依据预先定义的内部验证规则和后续独立证据。

## 7. 统计单位与解释边界

- 统计单位是26个物理物体，不是sensor pair、frame或Recording。
- 三个split seeds复用相同26个物体；seed间结果不能当作独立数据集。
- 物体级bootstrap仅作为描述性不确定性摘要。
- G0活动传感器mask由全压力档案非零时间变化冻结；不使用标签，但具有全档案无监督统计信息，论文需披露。
- Pearson相关表示指定时间窗口下的统计关系，不解释为因果作用或无误差物理真值。
- 当前结果限于STAG pressure-only，不推及其他硬件或所有日常物体。

## 协议修订记录（2026-11-22，Revision 1）

初始先导运行在前5个外层fold上使用30 epochs上限。五折的内部验证最优epoch分别落在29、29、29、29、30轮，Node-MLP训练/验证曲线在30轮附近仍有改善信号。该证据来自内部验证，不使用外层测试指标决定训练预算。为避免把人为预算上限误认为收敛，正式G2-R2运行将最大训练预算提高到 **50 epochs**，patience调整为 **8**，min_delta仍为1e-5。

- 前5折的30-epoch结果保留为pilot诊断，不与正式50-epoch结果合并，也不作为最终性能汇总。
- 正式50-epoch实验使用独立输出目录，重新运行全部15个外层fold；三个split seeds、内部验证物体、样本调度、模型候选、优化器和测试协议保持不变。
- 如果正式运行中最优epoch仍触及50轮上限，必须标记为右删失的训练预算结果，不能宣称已收敛；需再决定是否追加更长预算。
- 所有候选模型继续使用Node-MLP内部验证选出的共同epoch，以保持训练预算匹配。
